# Digital-Mastermind-Game
# This program is a digital recreation of the board game Mastermind
# Running the MastermindMain.java file prompts the start of the game
# The computer randomly generates a 4 color code to be guessed by the player
# The guessing is done in a style similar to Wordle or games of that genre, with hints
# The game has limited UI implementation/aesthetic work as that was not required for the scope of the project
